隐私说明

更新于 2026 年 11 月 12 日

本说明适用于由 GitHub 用户 qjq1106 维护的 DeepSeek Harness 个人本机 Google 工作区集成，覆盖本机 Google Workspace CLI、MCP 适配器和 Harness 会话中的相关数据处理。

访问的数据与用途

本集成根据用户发出的任务调用 Google API。当前授权范围覆盖 Drive 文件读写、Gmail 邮件与标签的读取和修改、日历读写，以及联系人只读。Google 登录还涉及基本账号身份信息。

  • 邮件任务可能涉及邮件标题、正文、收发件人、附件和标签，用于搜索、整理、总结或按指令处理邮件。
  • 文件任务可能涉及文件名称、元信息、内容和共享设置，用于查找、读取、下载、上传或管理文件。
  • 日历任务可能涉及日程标题、时间、说明和参与者，用于查询安排或按指令管理日程。
  • 联系人任务可能涉及姓名、邮箱、电话和其他已保存资料，用于查找联系人。

具体读取的内容取决于任务和 API 请求的字段。修改、发送、共享或删除操作依据用户指令执行。

本机处理与模型服务

Google API 的响应先由本机 CLI 和 MCP 适配器处理，再进入 Harness 的工具结果或会话上下文。模型执行任务时，相关会话内容可能发送给 Harness 中配置的模型服务提供方及其接入网关。

模型服务对请求内容的保存、使用和删除方式由该服务的条款及账号设置决定。使用者需要核对当前配置的服务及其数据政策。模型提供方的具体数据保留期限尚未由本集成独立核实。

本机适配器将 API 响应交给当前任务使用，数据处理范围由任务内容、已授予的权限和 Harness 配置共同决定。

保存位置与期限

Google Workspace CLI 将 OAuth 令牌加密保存在本机，并通过 Windows 凭据机制保护加密密钥。桌面 OAuth 客户端配置以本机配置文件保存。

读取的工具结果和生成内容可能保存在 Harness 的本机会话历史中。用户主动下载的文件、导出的内容和任务创建的临时文件也可能保留在本机，直到用户删除或由相关软件按自身规则清理。本集成尚未设置统一的自动到期删除周期。

Google 云端的邮件、文件、日程和联系人由 Google 服务管理。模型服务端的数据保存期限以当前提供方的实际政策为准。

撤销授权与删除数据

用户可在 Google 账号的第三方连接设置中撤销 DeepSeek Harness 的访问权限。撤销后，再次访问需要重新授权。

用户可清理本机 CLI 的授权凭证、Harness 会话历史及已下载或导出的文件。撤销 Google 授权后，已生成的本机副本仍需要分别清理。模型服务端的历史内容可按对应服务提供的方式申请删除。
