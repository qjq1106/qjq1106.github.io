本机 Google 工作区集成

在自己的电脑上，
处理 Google 工作内容。

通过本机 Google Workspace CLI 和 MCP 适配器，让 DeepSeek Harness 按用户指令查询邮件、管理文件、处理日历和查找联系人。

由 GitHub 用户 qjq1106 维护，供本人连接自己的 Google 账号使用。

可以处理的内容

Gmail
搜索和阅读邮件、处理标签，并按用户指令修改邮件状态或发送邮件。
Google Drive
搜索、读取和下载文件，并按用户指令上传、整理或修改文件。
Google Calendar
查询日历和日程，并按用户指令创建、更新或删除日程。
Google Contacts
读取联系人资料，帮助查找姓名、邮箱和相关联系信息。

数据如何流转

Google API 返回的数据由本机 CLI 和 MCP 适配器交给 Harness。任务需要模型理解这些内容时，相关内容会随会话发送给 Harness 中配置的模型服务提供方。

OAuth 令牌通过本机 CLI 加密保存。工具结果和任务内容可能保存在本机 Harness 会话记录中。模型服务的数据处理方式取决于当前提供方及其账号设置。

授权与支持

Google 登录和授权由账号所有者在 Google 页面完成。用户可在 Google 账号的第三方连接设置中撤销本集成的访问权限。

需要联系维护者时，可使用 Google 授权页面中显示的应用支持邮箱。
